# 项目结构

## 1. 架构说明

本项目为 Astro 纯静态站点，采用 Astro 原生约定的**路由即页面**模式，而非传统的分层/模块架构。产品三大核心板块的映射关系：

| 核心板块 | 对应目录 | 说明 |
|----------|----------|------|
| 内容创作与管理 | `src/content/blog/` | Markdown 文件 + frontmatter 元数据 |
| 阅读与发现 | `src/pages/` + `src/components/` | 路由页面 + 搜索/标签/分类 UI |
| 分发与互动 | `src/layouts/` + `src/components/GiscusComments.astro` | SEO 布局 + 评论组件 |

## 3. 关键文件说明 (Key Files)

| 文件 | 作用 |
|------|------|
| `astro.config.mjs` | Astro 核心配置：站点 URL、集成（Tailwind、Preact、sitemap）、构建输出目录 |
| `tailwind.config.mjs` | TailwindCSS 配置：`content` 扫描路径、`darkMode: 'class'` 策略 |
| `src/content/config.ts` | 定义文章 frontmatter Schema（title、date、category、tags 等字段校验） |
| `src/utils/constants.ts` | 站点名称、描述、GitHub 用户名等全局常量，所有页面引用此文件 |
| `.github/workflows/deploy.yml` | CI/CD：`pnpm build` → 部署 `dist/` 到 `gh-pages` 分支 |
| `.nvmrc` | 锁定 Node.js 版本，团队成员 `nvm use` 即可统一环境 |

## 4. 模块说明 (Module Description)

### 4.1 内容层 — `src/content/`
- 所有文章以 Markdown 文件存放在 `blog/` 目录
- 文件名即为 URL slug（如 `my-first-post.md` → `/blog/my-first-post`）
- 每篇文章通过 frontmatter 声明元数据（title、date、category、tags、description）
- `config.ts` 定义 Zod Schema，Astro 在构建时自动校验

### 4.2 路由层 — `src/pages/`
- Astro 基于文件系统的路由：`src/pages/about.astro` → `/about`
- 动态路由使用 `[param].astro` 语法：`blog/tag/[tag].astro` → `/blog/tag/astro`
- 首页 `index.astro` 查询 Content Collections，按日期倒序展示文章列表

### 4.3 布局层 — `src/layouts/`
- `BaseLayout.astro` 是所有页面的最外层壳：包含 `<html>`、`<head>`（SEO）、Header、Footer
- `BlogPostLayout.astro` 继承 BaseLayout，增加文章正文渲染 + Giscus 评论区
- 布局间通过 Astro 的 `<slot />` 嵌套，避免重复代码

### 4.4 组件层 — `src/components/`
- `.astro` 后缀为纯静态组件（零 JS），用于无交互的 UI 片段（Header、Footer、PostCard）
- `.tsx` 后缀为 Preact Island 组件，用于需要客户端交互的场景（搜索框、主题切换）

## 5. 文件放置规则 (Placement Rules)

| 类型 | 位置 | 判断标准 |
|------|------|----------|
| 路由/页面 | `src/pages/` | 可通过 URL 直接访问的页面 |
| 文章内容 | `src/content/blog/` | Markdown 格式的长文内容 |
| 布局模板 | `src/layouts/` | 被多个页面复用的 HTML 骨架 |
| 通用组件 | `src/components/` | 可在多个页面/布局中复用的 UI 片段 |
| 交互组件 | `src/components/*.tsx` | 需要客户端 JS 的组件（Preact Island） |
| 工具函数 | `src/utils/` | 纯函数，无 UI，无副作用 |
| 类型定义 | `src/types/` | 跨模块共享的 TypeScript interface/type |
| 全局样式 | `src/styles/` | TailwindCSS 指令、CSS 变量、代码主题 |
| 静态资源 | `public/` | 不经 Astro 处理的文件（favicon、robots.txt） |
| CI/CD 配置 | `.github/workflows/` | GitHub Actions 工作流定义 |

## 6. 构建产物 (Build Output)

```
dist/                              # astro build 输出，部署到 gh-pages
├── index.html
├── about/index.html
├── blog/
│   ├── my-first-post/index.html
│   ├── category/astro/index.html
│   └── tag/tutorial/index.html
├── search/index.html
├── pagefind/                      # Pagefind 生成的搜索索引
├── _astro/                        # Astro 打包的静态资源（CSS、JS、图片）
├── favicon.svg
└── robots.txt
```

每个页面输出为 `目录/index.html` 结构，确保 URL 无 `.html` 后缀且干净可读。
