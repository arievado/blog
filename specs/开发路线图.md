# 项目开发路线图 (Development Roadmap)

## 0. 策略概览

- **开发策略**: 自底向上——先搭地基（项目骨架、布局、内容 Schema），再建核心业务（首页、文章详情、分类/标签/归档），最后补充增强功能（搜索、暗色模式、评论、SEO 精调）。
- **MVP 目标**: 2 周内完成 M1，实现「能写（Markdown 发布）、能看（文章浏览）、能分类（标签/归档）」的最简闭环并部署到 GitHub Pages。

**模块依赖关系**：

```
  项目脚手架 (astro init, pnpm, TailwindCSS)
       ↓
  类型定义 + 站点常量 (src/types/, src/utils/constants.ts)
       ↓
  Content Collections Schema (src/content/config.ts)
       ↓
  BaseLayout (SEO 骨架) → Header + Footer
       ↓
  首页 ─┬─ 文章详情页 ─ 评论区 (M2)
        ├─ 分类/标签列表页
        ├─ 归档页
        └─ 关于页 / 友链页 (友链 M2)
       ↓
  搜索 (M2) → 深色模式 (M2) → SEO 精调 (M2)
       ↓
  部署 (贯穿 M1→M2，首次部署在 M1.5)
```

## 1. 里程碑一：MVP (核心闭环)

> 目标：2 周内完成，实现「写 Markdown → 自动构建 → 页面可浏览」的最简闭环并部署上线。

### Phase 1.1: 项目脚手架 (Scaffolding)

- [ ] **1.1.1 初始化 Astro 项目**
    - **关联模块**: 项目根目录、`package.json`、`astro.config.mjs`
    - **产出**: `pnpm create astro@latest` 初始化项目，选择 Empty 模板 + TypeScript
    - **验证**: `pnpm dev` 能启动开发服务器

- [ ] **1.1.2 安装并配置工具链**
    - **关联模块**: `tailwind.config.mjs`、`eslint.config.mjs`、`prettier.config.mjs`、`tsconfig.json`
    - **产出**: TailwindCSS（`@astrojs/tailwind`）、ESLint + `eslint-plugin-astro`、Prettier + `prettier-plugin-astro` + `prettier-plugin-tailwindcss`
    - **验证**: 所有配置文件就位，`eslint .` 和 `prettier --check .` 无报错

- [ ] **1.1.3 创建目录结构**
    - **关联模块**: `src/` 下所有子目录
    - **产出**: 按 `specs/项目结构.md` 创建完整目录树（`src/content/blog/`、`src/pages/`、`src/layouts/`、`src/components/`、`src/utils/`、`src/types/`、`src/styles/`）
    - **验证**: 目录结构与 `specs/项目结构.md` 一致

- [ ] **1.1.4 配置 GitHub Actions 部署**
    - **关联模块**: `.github/workflows/deploy.yml`
    - **产出**: 配置 `astro build` + 部署到 `gh-pages` 分支的 workflow
    - **验证**: 推送到 `main` 分支后自动触发构建

### Phase 1.2: 内容层 (Content Foundation)

- [ ] **1.2.1 定义类型系统**
    - **关联模块**: `src/types/index.ts`、`src/utils/constants.ts`
    - **产出**: `Article`、`Frontmatter`、`Category`、`Tag` 等 interface；`SITE_TITLE`、`SITE_DESCRIPTION`、`POSTS_PER_PAGE` 等常量
    - **验证**: TypeScript 编译无错误

- [ ] **1.2.2 定义 Content Collections Schema**
    - **关联模块**: `src/content/config.ts`
    - **产出**: 定义 `blog` collection 的 Zod Schema，包含 `title`、`date`、`category`、`tags`、`description`、`draft` 字段
    - **验证**: 添加一篇测试文章，`astro check` 正确识别并校验 frontmatter

- [ ] **1.2.3 编写内容查询工具**
    - **关联模块**: `src/utils/content.ts`、`src/utils/date.ts`
    - **产出**: `getAllPosts()`（排序+过滤草稿）、`getPostsByCategory()`、`getPostsByTag()`、`getAllCategories()`、`getAllTags()`、`formatDate()`
    - **验证**: 导入到任意 `.astro` 页面可正常调用

- [ ] **1.2.4 创建示例文章**
    - **关联模块**: `src/content/blog/`
    - **产出**: 2-3 篇示例 Markdown 文章，覆盖不同的分类和标签，含代码块和图片
    - **验证**: `astro dev` 中通过 Content Collections API 可查询到文章

### Phase 1.3: 布局与导航 (Layout & Shell)

- [ ] **1.3.1 全局样式**
    - **关联模块**: `src/styles/global.css`
    - **产出**: TailwindCSS 指令（`@tailwind base/components/utilities`）、`prose` 文章排版样式、代码高亮主题
    - **验证**: 深色模式 CSS 变量就位

- [ ] **1.3.2 SEO 组件**
    - **关联模块**: `src/components/SEO.astro`
    - **产出**: 接收 `title`、`description`、`ogImage` Props，输出 `<title>`、`<meta>`、`og:` 标签
    - **验证**: 渲染页面 `<head>` 中包含完整 meta 标签

- [ ] **1.3.3 Header + Footer**
    - **关联模块**: `src/components/Header.astro`、`src/components/Footer.astro`
    - **产出**: Header（Logo、导航菜单：首页/归档/关于/友链/搜索）、Footer（链接、版权）
    - **验证**: 独立渲染，移动端导航可用（汉堡菜单或折叠）

- [ ] **1.3.4 BaseLayout**
    - **关联模块**: `src/layouts/BaseLayout.astro`
    - **产出**: 组合 SEO + Header + `<slot />` + Footer 的全局布局，`<html class="">` 支持暗色模式
    - **验证**: 任意页面继承 BaseLayout 后获得完整 HTML 骨架

### Phase 1.4: 核心页面 (Core Pages)

- [ ] **1.4.1 首页 — 文章列表**
    - **关联模块**: `src/pages/index.astro`、`src/components/PostCard.astro`、`src/components/PostList.astro`
    - **产出**: 按日期倒序展示文章卡片（标题、日期、摘要、分类、标签），含分页
    - **验证**: 首页渲染所有非草稿文章

- [ ] **1.4.2 文章详情页**
    - **关联模块**: `src/pages/blog/[...slug].astro`、`src/layouts/BlogPostLayout.astro`
    - **产出**: Markdown 正文渲染、文章标题、日期、分类/标签标签、返回链接
    - **验证**: 点击首页文章卡片 → 跳转到详情页 → 内容完整渲染

- [ ] **1.4.3 分类列表页**
    - **关联模块**: `src/pages/blog/category/[category].astro`、`src/components/CategoryList.astro`
    - **产出**: 展示某分类下的所有文章列表
    - **验证**: 从文章详情点击分类名 → 跳转到分类列表 → 显示该分类所有文章

- [ ] **1.4.4 标签列表页**
    - **关联模块**: `src/pages/blog/tag/[tag].astro`、`src/components/TagCloud.astro`
    - **产出**: 展示某标签下的所有文章列表
    - **验证**: 从文章详情点击标签名 → 跳转到标签列表 → 显示该标签所有文章

- [ ] **1.4.5 归档页**
    - **关联模块**: `src/pages/archive.astro`
    - **产出**: 按年月分组的时间线式文章归档
    - **验证**: 所有文章出现在归档页中，按日期分组正确

- [ ] **1.4.6 关于页**
    - **关联模块**: `src/pages/about.astro`、`src/layouts/PageLayout.astro`
    - **产出**: 个人介绍、技能、联系方式，内容从 Markdown 或常量读取
    - **验证**: 访问 `/about` 正常渲染

- [ ] **1.4.7 404 页面**
    - **关联模块**: `src/pages/404.astro`
    - **产出**: 友好的 404 提示 + 返回首页链接
    - **验证**: 访问不存在路径时显示 404 页面

### Phase 1.5: 首次部署

- [ ] **1.5.1 构建验证**
    - **产出**: `pnpm build` 成功生成 `dist/`，所有页面为静态 HTML
    - **验证**: `dist/` 目录结构正确，本地 `pnpm preview` 可浏览

- [ ] **1.5.2 部署到 GitHub Pages**
    - **产出**: 推送 `main` 分支触发 GitHub Actions → 自动部署到 `gh-pages` → 通过 `<username>.github.io` 可访问

## 2. 里程碑二：功能完善 (Feature Complete)

> 目标：2 周内补充搜索、暗色模式、评论、SEO，从「能用」到「好用」。

    - **产出**: 结果列表（标题、摘要、高亮匹配词）、无结果提示、加载中状态

### Phase 2.2: 深色模式

    - **验证**: 点击切换 → 刷新保持 → 跟随系统偏好（首次访问）

- [ ] **2.2.2 深色模式样式适配**
    - **关联模块**: `src/styles/global.css`、TailwindCSS `dark:` 前缀

- [ ] **2.3.1 集成 Giscus**

- [ ] **2.3.2 评论样式适配**

    - **验证**: 两种主题下评论区风格与博客整体风格协调

    - **关联模块**: `src/components/SEO.astro`、`astro.config.mjs`

    - **关联模块**: `src/pages/friends.astro`

**使用指南**:
1. 按 Phase 顺序依次开发，每个 Phase 内的任务可从 `1.1.1` 开始顺序执行
2. 每完成一个任务，勾选对应的 `- [ ]` → `- [x]`
3. 每个 Phase 完成后，执行该 Phase 下所有「验证」项，确认无回归
4. 遇到阻塞（依赖未就绪、工具问题），在阻塞任务行尾标注 `⚠️ 阻塞原因`
