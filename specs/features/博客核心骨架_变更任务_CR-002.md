## 2. 增量任务

### Task-07 ✅：Giscus 评论配置与验证

**通俗解释**：给博客加上评论区——文章底部出现 GitHub 登录的评论框，读者可以直接留言。

**做什么**：
1. 在 `arievado/blog` 仓库启用 GitHub Discussions
2. 从 giscus.app 获取配置值（repo-id, category-id）
3. 创建 `.env` 填入真实配置值
4. 更新 `.github/workflows/deploy.yml` 注入 PUBLIC_GISCUS_* 环境变量
5. 更新 GiscusComments.astro：添加 `crossorigin="anonymous"` 和 `async` 属性
6. 验证本地构建产物包含 Giscus 脚本
7. 验证未配置时评论区隐藏且无报错（回退场景）

**涉及文件**：
- `.env`（新建）
- `.github/workflows/deploy.yml`（修改）
- `src/components/GiscusComments.astro`（修改）

**参考**：AC-030, AC-031, AC-032, AC-033

**依赖**：无（GiscusComments 组件在 Task-04 中已挂载到 BlogPostLayout）

**预估工时**：15 分钟

**验证标准**：

- [x] 配置后 `pnpm build` 产物包含 Giscus 脚本
  - **Given**  `.env` 配置了真实的 PUBLIC_GISCUS_*，**When** 执行 `pnpm build`，**Then** 所有文章详情页 HTML 包含 `giscus.app/client.js` 脚本标签
- [x] 访客在文章底部可见评论区
  - **Given** 部署后访问文章页，**When** 滚动到底部，**Then** 显示 Giscus 评论框
- [x] 评论框主题跟随站点
  - **Given** 站点为深色模式，**When** 加载评论区，**Then** 评论框为深色主题
- [x] 未配置时隐藏评论区
  - **Given** `.env` 中 Giscus 变量为占位符或缺失，**When** 构建并访问文章页，**Then** 文章底部无 Giscus 相关 DOM
