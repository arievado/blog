## 2. 增量任务

### Task-15：Header 顶层导航项添加图标

**通俗解释**：给顶栏的"首页"和"关于"配上小图标，跟"文章"下拉菜单里的图标保持一套风格。

**做什么**：
1. `topLevelItems` 每项增加 `icon` 字段，存储 SVG 内联字符串
2. 首页用房子图标（home），关于用用户图标（user），风格与 dropdownItems 一致（线条风、16x16、`stroke="currentColor"`）
3. 模板渲染时用 `<Fragment set:html={item.icon} />` 插入图标（与 dropdownItems 相同的渲染方式）
4. 移动端汉堡菜单中的顶层项同步应用图标

**图标参考**：
- 首页（home）：`<path d="M3 9l9-7 9 7v11a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2z"/><polyline points="9 22 9 12 15 12 15 22"/>`
- 关于（user）：`<path d="M20 21v-2a4 4 0 0 0-4-4H8a4 4 0 0 0-4 4v2"/><circle cx="12" cy="7" r="4"/>`

**涉及文件**：`src/components/Header.astro`

**参考**：技术方案 5.1 → AC-043

**依赖**：无（Header 结构已稳定）

**预估工时**：15 分钟

**验证标准**（TDD RED 阶段依据）：

  - **Given** Header 源文件，**When** 检查桌面端和移动端导航渲染逻辑，**Then** topLevelItems 的 `<a>` 标签内包含 `<Fragment set:html={item.icon} />` 或等效图标渲染

### Task-16：Sidebar 导航项去重 + 图标

**通俗解释**：侧边栏不再重复展示"分类""标签""归档"（它们已经在顶部"文章"下拉里了），只保留"首页""关于""友链"，每项前面换成图标，看起来更清爽整齐。

**做什么**：
1. **缩减 navItems**：从 6 项改为 3 项——保留 首页、关于、友链；去除 归档、分类、标签
2. **增加图标字段**：每项新增 `icon`，使用与 Header 相同的图标 SVG（首页=home、关于=user、友链=link）
3. **替换短线装饰**：将 `<span>—</span>` 短线替换为 `<Fragment set:html={item.icon} />`
4. **保持交互效果**：`hover:translate-x-1 transition-transform` 和颜色过渡保留不变
5. 友链图标：用链接图标 `<path d="M15 7h3a5 5 0 0 1 5 5 5 5 0 0 1-5 5h-3m-6 0H6a5 5 0 0 1-5-5 5 5 0 0 1 5-5h3"/><line x1="8" y1="12" x2="16" y2="12"/>`

**涉及文件**：`src/components/Sidebar.astro`

**参考**：技术方案 5.6 d) → AC-040

**依赖**：无（Sidebar 已独立存在）

**预估工时**：15 分钟

**验证标准**（TDD RED 阶段依据）：

- [x] navItems 仅含 3 项且不含分类/标签/归档
  - **Given** Sidebar.astro 源文件，**When** 检查 navItems 数组，**Then** 长度为 3，包含首页/关于/友链，不含 `/archive/`、`/blog/category/`、`/blog/tag/`
- [x] 每项 navItem 含 `icon` 字段
  - **Given** Sidebar.astro 源文件，**When** 检查 navItems 定义，**Then** 每项含 `icon` 字段（非空 SVG 字符串）
- [x] 导航渲染使用图标而非短线
  - **Given** Sidebar 源文件，**When** 检查导航 `<a>` 标签内，**Then** 不含 `—` 短线字符，包含 `<Fragment set:html={item.icon} />` 或等效图标渲染
