## 2. 增量任务

### Task-20：新增 B站/QQ音乐/邮箱图标 + icon 映射重构为字典

**通俗解释**：侧边栏社交图标区从只有一个 GitHub 变成一排四个图标，结构上也改成"字典查表"方式，以后再想加别的平台只加两行就行。

**做什么**：

1. **`src/site.config.ts`**：socialLinks 数组追加 B站、QQ音乐、邮箱三条（URL 用占位符）
2. **`src/components/Sidebar.astro`**：
   - 将 social icons 区现有的 `{link.icon === "xxx" && <svg>...}</svg>` 条件链替换为 `iconMap` 字典：
     ```ts
     const iconMap: Record<string, string> = {
       github: `<svg class="h-5 w-5" viewBox="0 0 24 24" fill="currentColor">...</svg>`,
       bilibili: `<svg class="h-5 w-5" viewBox="0 0 24 24" fill="currentColor">...</svg>`,
       qqmusic: `<svg class="h-5 w-5" viewBox="0 0 24 24" fill="currentColor">...</svg>`,
       email: `<svg class="h-5 w-5" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">...</svg>`,
     };
     ```
   - 渲染用 `<Fragment set:html={iconMap[link.icon]} />` 替代 if/else 链
   - 兜底：icon 不在字典中时不渲染（不报错）
3. B站 SVG 图标用线条风格（与现有图标一致），QQ音乐用音符 + 耳机组合的线条图标

**涉及文件**：`src/site.config.ts`、`src/components/Sidebar.astro`

**参考**：AC-039

**依赖**：无

**预估工时**：20 分钟

**验证标准**（TDD RED 阶段依据）：

- [ ] socialLinks 配置中包含 4 条记录（GitHub / B站 / QQ音乐 / 邮箱）
  - **Given** `src/site.config.ts`，**When** 检查 socialLinks 数组，**Then** 数组长度 ≥ 4，包含 icon 为 `github`、`bilibili`、`qqmusic`、`email` 的条目
- [ ] Sidebar 中 icon 渲染使用字典查找而非 if/else 链
  - **Given** `Sidebar.astro` 源文件，**When** 检查 social links 渲染逻辑，**Then** 存在 `Record<string, string>` 字典且通过 `iconMap[link.icon]` 查找
- [ ] 首页侧边栏同时显示 4 个社交图标于同一行
  - **Given** 构建后站点首页，**When** 查看侧边栏社交图标区，**Then** GitHub / B站 / QQ音乐 / 邮箱 4 个图标横向排列于同一行，间距均匀
- [ ] 各图标点击跳转到对应链接（新标签页）
  - **Given** 首页已加载，**When** 点击 B站图标，**Then** 新标签页打开 `https://space.bilibili.com/xxxxx`
- [ ] 邮箱链接使用 `mailto:` 协议
  - **Given** 首页已加载，**When** 检查邮箱图标的 href，**Then** 为 `mailto:contact@example.com`
- [ ] 后续新增平台只需加配置 + iconMap 条目
  - **Given** 想新增一个社交平台，**When** 在 `site.config.ts` socialLinks 加一条 + `iconMap` 加一个 key，**Then** 无需修改其他代码即可渲染新图标
