# 博客核心骨架 — 功能需求说明书

## 1. 背景与价值

**为什么做**：博客站点需要最基本的内容展示能力——能写文章、能看文章、能按分类/标签/时间归档、能在手机和桌面上正常阅读。这是整个数字花园的地基，没有这个地基，后续搜索、评论等增强功能都无从谈起。

**做成什么样**：搭建一个干净、好用、响应式的博客前端，涵盖首页、文章详情、分类、标签、归档、关于六大页面，支持深色/浅色主题切换，推送代码即自动部署上线。

---

## 2. 范围

### 本次做

- 首页：左侧个人信息栏（头像/昵称/简介/社交图标/统计/导航）+ 右侧文章列表，两栏布局
- 文章详情页：Markdown 完整渲染 + 代码语法高亮
- 分类页：分类列表 → 分类下文章
- 标签页：标签列表 → 标签下文章
- 归档页：文章按年月分组倒序展示
- 关于页：静态 Markdown 渲染
- 深色/浅色主题切换（默认跟随系统，支持手动切换并记忆）
- 响应式布局（手机 / 平板 / 桌面）
- 全局导航
- GitHub Actions 自动构建部署到 GitHub Pages
- Sitemap 自动生成
- 404 页面
- 文章 URL 结构：`/posts/<slug>/`
- 社交链接配置（GitHub 等），在首页 Sidebar 展示

### 本次不做

- 文章目录（TOC）— 第二批
- Pagefind 全文搜索 — 第二批
- Giscus 评论系统 ✅
- 草稿功能（`draft: true`）— 第二批
- 置顶文章 — 第二批
- 首页分页 — 文章多了再加
- RSS 订阅、访问统计、社交分享 — 暂不做

## 4. 需求详述

### 4.1 核心流程

1. 访客打开首页 → 左侧看到个人信息栏（头像/昵称/简介/社交图标/统计/导航），右侧看到已发布文章列表（标题、发布日期、摘要）→ 点击文章进入详情页
2. 访客点击导航栏"文章"下拉 → 展开菜单显示分类/标签/归档三个入口（各带图标）→ 点击进入对应页面
3. 访客打开关于页 → 看到作者介绍（静态 Markdown 渲染）
4. 访客切换主题 → 一键切换深色/浅色 → 偏好被记住，下次访问保持
5. 访客阅读文章 → 滚动到文章底部 → 看到 Giscus 评论区 → 登录 GitHub 后发表评论

### 4.2 交互规则

- 深色/浅色切换按钮全局可见，切换时平滑过渡
- 移动端导航收缩为汉堡菜单，文章二级菜单在汉堡菜单内展开
- 桌面端导航栏"文章"为下拉菜单，点击展开、再次点击或点击外部区域关闭
- 代码块超长行时出现水平滚动条，不撑破布局
- 文章列表中超长标题截断加省略号
- 图片缺失时显示占位提示文本，不用浏览器默认裂图
- Giscus 评论区自动跟随站点深浅色主题，评论文本支持 Markdown 格式
- Giscus 未配置时评论区隐藏，不显示报错信息
- 首页采用两栏布局，左侧 Sidebar 固定宽度，右侧文章列表自适应剩余空间
- 移动端（<1024px）Sidebar 堆叠在文章列表上方，变为单栏布局

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 文章 Slug 全局唯一，通过 URL `/posts/<slug>/` 访问 |
| BR-002 | 每篇文章必须有且仅有一个分类，未指定时归为"未分类" |
| BR-003 | 每篇文章可有零至多个标签 |
| BR-004 | 文章发布日期统一显示为 `YYYY-MM-DD` 格式 |
| BR-005 | 主题偏好存储在浏览器 localStorage，浏览器未存储时跟随系统设置 |
| BR-006 | Giscus 评论区通过 GitHub Discussions 存储，评论数据不经过自有服务器 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001** — 首页文章列表
  - **Given** 存在已发布文章，**When** 访客打开首页，**Then** 文章列表显示，每篇包含标题、发布日期、摘要

- [x] **AC-002** — 首页个人信息栏
  - **Given** 站点已配置头像和简介，**When** 访客打开首页，**Then** 左侧个人信息栏显示作者头像、昵称和简介文字，右侧显示文章列表

- [ ] **AC-003** — 文章详情页 Markdown 渲染
  - **Given** 存在一篇已发布文章，**When** 访客打开 `/posts/<slug>/`，**Then** 正文 Markdown 正确渲染：代码块带语法高亮、图片正常显示、表格/列表/加粗/引用块均正确呈现

- [ ] **AC-004** — 分类列表页
  - **Given** 已有文章且分配了分类，**When** 访客打开分类页，**Then** 看到全部分类；点击某个分类，显示属于该分类的文章列表

- [ ] **AC-005** — 标签列表页
  - **Given** 已有文章且打了标签，**When** 访客打开标签页，**Then** 看到全部标签列表（含每标签文章数量）；点击某个标签，显示包含该标签的文章列表

- [ ] **AC-006** — 归档页
  - **Given** 已有文章且各有发布日期，**When** 访客打开归档页，**Then** 文章按年月分组倒序排列，每篇显示标题和日期

- [ ] **AC-007** — 关于页
  - **Given** 关于页 Markdown 已编写，**When** 访客打开关于页，**Then** 看到渲染后的关于内容

- [ ] **AC-008** — 首次访问主题跟随系统
  - **Given** 访客首次打开站点（localStorage 无主题记录），**When** 页面加载完成，**Then** 主题自动匹配操作系统深浅色设置

- [ ] **AC-009** — 手动切换并记忆主题
  - **Given** 访客已在站点内，**When** 访客点击主题切换按钮，**Then** 主题立即切换；关闭浏览器后再次打开，仍保持上次选择

- [ ] **AC-010** — 移动端响应式
  - **Given** 访客使用手机浏览器（宽度 < 768px），**When** 浏览任意页面，**Then** 布局自适应屏幕，文字舒适可读，导航变为汉堡菜单

- [ ] **AC-011** — 平板端响应式
  - **Given** 访客使用平板浏览器（宽度 768px-1024px），**When** 浏览任意页面，**Then** 布局自适应，充分利用屏幕宽度

- [x] **AC-012** — 全局导航
  - **Given** 站点有多个页面，**When** 访客在任意页面，**Then** 桌面端导航栏显示「首页」「文章▼」「关于」；移动端汉堡菜单显示完整导航结构

- [ ] **AC-013** — Sitemap 自动生成
  - **Given** 站点构建完成，**When** 构建产物生成，**Then** 包含有效的 `sitemap.xml`，列出所有已发布文章的 URL

- [ ] **AC-014** — 自动部署
  - **Given** 代码推送到主分支，**When** GitHub Actions 触发，**Then** 站点自动构建并部署到 GitHub Pages，无需人工操作

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-015** — 空文章状态
  - **Given** 站点尚无任何文章，**When** 访客打开首页/分类/标签/归档页，**Then** 显示友好空状态提示，而非空白页面

- [ ] **AC-016** — 空分类/标签
  - **Given** 某个分类或标签下没有文章，**When** 访客点击该分类/标签，**Then** 显示"该分类/标签下暂无文章"友好提示

- [ ] **AC-017** — 未分类文章
  - **Given** 一篇文章没有指定分类，**When** 该文章在列表或详情页中展示，**Then** 分类字段显示为"未分类"

- [ ] **AC-018** — 无标签文章
  - **Given** 一篇文章没有标签，**When** 打开该文章详情页，**Then** 不显示标签区域

- [ ] **AC-019** — 图片缺失
  - **Given** 文章引用了不存在的本地图片，**When** 文章渲染，**Then** 显示占位提示（"图片未找到"），不使用浏览器默认裂图

- [ ] **AC-020** — 超长标题截断
  - **Given** 某篇文章标题特别长，**When** 在文章列表展示，**Then** 标题超出部分以省略号截断，列表布局不被撑破

- [ ] **AC-021** — 代码块长行滚动
  - **Given** 文章包含一行很长的代码，**When** 在移动端查看，**Then** 代码块出现水平滚动条，不撑破页面布局

- [ ] **AC-022** — Frontmatter 校验失败
  - **Given** 某篇 Markdown frontmatter 格式错误，**When** 构建执行，**Then** 构建失败并输出清晰错误信息（指出哪个文件、什么字段有问题）

- [ ] **AC-023** — 404 页面
  - **Given** 访客访问不存在的 URL，**When** 页面加载，**Then** 显示 404 页并提供返回首页链接

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-024** — 文章 Slug 唯一性 ← BR-001
  - **Given** 存在两篇文章使用相同 slug，**When** 构建执行，**Then** 构建失败并提示 slug 冲突

- [ ] **AC-025** — 文章必须有分类 ← BR-002
  - **Given** 文章 frontmatter 未指定分类，**When** 该文章在任何地方展示，**Then** 分类字段显示为"未分类"

- [ ] **AC-026** — 日期格式 ← BR-004
  - **Given** 文章有发布日期，**When** 在任何页面渲染日期，**Then** 统一显示为 `YYYY-MM-DD` 格式（如 `2026-05-10`）

### 5.4 头像配置 (CR-001)

- [ ] **AC-027** — 头像路径通过配置文件设置
  - **Given** 站点配置了头像图片，**When** 全站任意页面渲染，**Then** 使用 `site.config.ts` 中指定的头像路径（不再硬编码在 constants.ts 中）

- [ ] **AC-028** — 头像全站展示
  - **Given** 站点已配置头像，**When** 访问任意页面，**Then** 导航栏站点标题旁显示头像

- [ ] **AC-029** — 头像缺失时显示占位
  - **Given** 配置的头像文件在 `public/` 下不存在，**When** 页面渲染头像时图片加载失败，**Then** 显示默认占位符（首字母或默认图标），不显示浏览器裂图

### 5.5 评论系统 (CR-002)

- [x] **AC-030** — 评论区正常加载
  - **Given** 已配置 Giscus 环境变量，**When** 访客打开文章详情页并滚动到底部，**Then** 显示 Giscus 评论区，含评论文本框和已有评论列表

- [x] **AC-031** — 评论主题跟随站点
  - **Given** 站点当前为深色/浅色模式，**When** Giscus 评论区加载，**Then** 评论框自动匹配当前主题配色

- [x] **AC-032** — 访客可发表评论
  - **Given** 评论区已加载，**When** 访客登录 GitHub 账号并输入评论内容提交，**Then** 评论成功发表并显示在评论列表中

- [x] **AC-033** — 未配置时评论区隐藏
  - **Given** Giscus 环境变量未正确配置（缺失或为占位符），**When** 访客打开文章详情页，**Then** 文章底部不显示评论区，也不显示任何报错信息

### 5.6 导航栏重构 (CR-003)

- [x] **AC-034** — 桌面端「文章」下拉菜单
  - **Given** 访客在桌面端（≥768px）打开任意页面，**When** 页面加载完成，**Then** 导航栏显示「首页」「文章▼」「关于」三项；「分类」「标签」「归档」入口不在导航栏直接可见

- [x] **AC-035** — 下拉菜单展开与关闭
  - **Given** 桌面端导航栏已加载，**When** 点击「文章」按钮，**Then** 下拉菜单展开，显示「📁 分类」「🏷️ 标签」「📅 归档」三个选项（各带图标）；再次点击「文章」按钮或点击页面其他区域，下拉菜单关闭

- [x] **AC-036** — 移动端文章子菜单
  - **Given** 访客在移动端（<768px）打开汉堡菜单，**When** 菜单展开，**Then**「文章」显示为折叠组（带展开箭头图标）；点击「文章」展开显示「分类」「标签」「归档」子项；子项略微缩进以区分层级

- [x] **AC-037** — 下拉菜单项图标
  - **Given**「文章」下拉菜单已展开，**When** 查看各菜单项，**Then** 每个选项前有对应 SVG 图标（分类和标签和归档各使用不同图标），图标与文字颜色一致，大小统一

### 5.7 首页侧边栏 (CR-004)

- [x] **AC-038** — 侧边栏统计数据
  - **Given** 站点存在已发布文章，**When** 访客打开首页，**Then** 侧边栏显示文章总数、分类总数、标签总数三项统计数据

- [x] **AC-039** — 侧边栏社交图标
  - **Given** `site.config.ts` 配置了社交链接，**When** 访客打开首页，**Then** 侧边栏显示社交图标按钮（如 GitHub），点击跳转到对应链接（新标签页打开）

- [x] **AC-040** — 侧边栏导航菜单
  - **Given** 站点有多个页面，**When** 访客打开首页，**Then** 侧边栏显示导航菜单，包含「首页」「归档」「分类」「标签」「关于」「友链」链接，点击可跳转到对应页面

- [x] **AC-041** — 桌面端两栏布局
  - **Given** 访客在桌面端（≥1024px）打开首页，**When** 页面加载，**Then** 呈现左右两栏布局：左侧固定宽度个人信息栏，右侧自适应宽度的文章列表

- [x] **AC-042** — 移动端侧边栏堆叠
  - **Given** 访客在移动端（<1024px）打开首页，**When** 页面加载，**Then** 个人信息栏堆叠在文章列表上方，各占满宽，图片和文字居中对齐
