## 2. 增量任务

### Task-18：统计区改为卡片式竖线分隔布局

**通俗解释**：把统计数据改成"大数字在上、标签在下、竖线分隔"的卡片样式，看起来更像正式的数据看板。

**做什么**：
1. 统计区改为三层结构：外层容器（卡片背景 + 圆角 + 内边距）、中层 flex 横排、内层每项（数字 + 标签上下排列）
2. 数字：`text-lg font-bold`，深色文字
3. 标签：`text-xs`，灰色文字（"篇文章"/"个分类"/"个标签"）
4. 项与项之间用竖线 `|` 分隔（`border-r` 或文字分隔符）
5. 深色模式下竖线和文字颜色适配

**期望效果**：
```
┌─────────────────────────┐
│   4   │   2   │   3    │
│  文章 │  分类 │  标签  │
└─────────────────────────┘
```

**涉及文件**：`src/components/Sidebar.astro`

**参考**：AC-038

**依赖**：无

**预估工时**：10 分钟

**验证标准**（TDD RED 阶段依据）：

- [x] 统计区数字使用大号加粗样式

- [x] 统计区三项间存在竖线分隔
  - **Given** Sidebar.astro 源文件，**When** 检查统计区代码，**Then** 存在 `border-r` 或 `|` 竖线分隔符
- [x] 统计区为卡片式容器
  - **Given** Sidebar.astro 源文件，**When** 检查统计区外层容器，**Then** 包含 `rounded` 和背景/边框样式类
