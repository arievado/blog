## 3. 变更详情

### 新增/修改的验收标准

- **AC-027**: 头像路径通过配置文件设置
  - **Given** 用户编辑 `site.config.ts` 修改 `avatar` 字段
  - **When** 构建站点
  - **Then** 全站所有引用头像的位置使用新路径

- **AC-028**: 头像全站展示
  - **Given** 站点已通过 `site.config.ts` 配置头像路径
  - **When** 访问任意页面（首页、文章详情、分类、标签、归档、关于）
  - **Then** 导航栏站点标题旁显示头像

- **AC-029**: 头像缺失占位
  - **Given** `site.config.ts` 配置的头像文件在 `public/` 下不存在
  - **When** 浏览器加载页面时头像 `<img>` 触发 `error` 事件
  - **Then** 头像区域显示占位文字（如站点名称首字），不显示浏览器默认裂图

### 技术变更

**`src/site.config.ts`** 结构：

```ts
export const siteConfig = {
  avatar: "/images/avatar.webp",
  bio: "...",
  author: "Author",
} as const;
```

**`constants.ts`** 从 `site.config.ts` 导入并重新导出，对外接口不变：

```ts
import { siteConfig } from "../site.config";
export const SITE_AVATAR = siteConfig.avatar;
export const SITE_BIO = siteConfig.bio;
export const SITE_AUTHOR = siteConfig.author;
```

**`Header.astro`** 标题区域变更（伪结构）：

```
原来：[站点标题]                     [导航链接] [主题按钮]
现在：[头像] [站点标题]              [导航链接] [主题按钮]
```

头像 `<img>` 添加 `onerror` 内联处理，失败时替换为占位 `<span>`。

#### Task-09：头像缺失占位处理

**通俗解释**：如果配置的图片文件丢了（比如还没放进去），不会显示难看的裂图，而是显示一个文字占位。

**涉及文件**：`src/components/Header.astro`、`src/pages/index.astro`

**参考**：本文档 5.1 节 → AC-029

**依赖**：Task-08（Header 已有头像 img）

**预估工时**：15 分钟

- [ ] Header 头像 img 标签含 onerror 处理逻辑

- [ ] Hero 区头像 img 标签含 onerror 处理逻辑
