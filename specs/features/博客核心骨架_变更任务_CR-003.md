## 2. 增量任务

### Task-08：导航栏重构 — 文章下拉菜单 + 图标

**通俗解释**：把顶栏变清爽——"分类""标签""归档"三个入口收到一个"文章"下拉菜单里，点一下展开，再点关闭。每个选项前面配个小图标，看起来更专业。

**做什么**：

1. **重构 `navItems` 数据结构**：
   - `navItems` 拆分为两组：`topLevelItems`（首页、关于）和 `dropdownItems`（分类/标签/归档，各带 `icon` 字段）
   - 桌面端渲染：遍历 `topLevelItems` → 「文章」下拉按钮 → 下拉面板遍历 `dropdownItems`

2. **实现桌面端下拉交互**（内联 `<script is:inline>`）：
   - 点击「文章」按钮：切换下拉面板显示/隐藏
   - 点击页面其他区域：关闭下拉
   - 点击下拉内链接：导航到目标页面，同时关闭下拉

3. **移动端汉堡菜单适配**：
   - 汉堡菜单中「文章」为折叠组（带展开箭头图标 ▸/▾）
   - 点击「文章」展开显示三个子项（略微缩进以示层级）
   - 子项结构与 `dropdownItems` 复用

4. **添加 SVG 图标**：
   - 分类：📁 文件夹图标（内联 SVG，约 200 字节）
   - 标签：🏷️ 标签图标（内联 SVG）
   - 归档：📅 日历/时钟图标（内联 SVG）
   - 图标 16x16，`inline-flex` 居中，与文字间距 `gap-2`

5. **样式细节**：
   - 下拉面板：白色背景、圆角、阴影、绝对定位在「文章」按钮下方
   - 下拉项 hover 效果与现有导航链接一致
   - 深色模式适配：`dark:` 变体覆盖背景和文字色

**涉及文件**：`src/components/Header.astro`

**参考**：AC-012(修改), AC-034, AC-035, AC-036, AC-037

**依赖**：Task-02（Header 基础结构已建立，在其上扩展）

**预估工时**：50 分钟

**验证标准**（TDD RED 阶段直接转化为测试用例）：

- [ ] 桌面端导航栏仅显示「首页」「文章▼」「关于」
  - **Given** 桌面端（≥768px）打开任意页面，**When** 页面加载，**Then** 导航栏只出现「首页」「文章▼」「关于」三项 + 主题切换按钮；「分类」「标签」「归档」不直接可见

- [ ] 点击「文章」展开下拉菜单，显示三个选项及图标
  - **Given** 桌面端导航栏已加载，**When** 点击「文章」按钮，**Then** 下拉面板在按钮下方弹出，依次显示带图标的「分类」「标签」「归档」三项；图标可见且各不相同

- [ ] 再次点击「文章」或点击外部区域，下拉关闭
  - **Given** 下拉菜单已展开，**When** 再次点击「文章」按钮或点击页面空白区域，**Then** 下拉菜单关闭（消失）

- [ ] 点击下拉内链接正确导航
  - **Given** 下拉菜单已展开，**When** 点击「分类」选项，**Then** 页面跳转至 `/blog/category/`，下拉菜单关闭

- [ ] 移动端汉堡菜单中「文章」为折叠组
  - **Given** 移动端（<768px）打开汉堡菜单，**When** 菜单展开，**Then**「文章」项右侧显示展开箭头（▸），下方子项默认不可见；点击「文章」后箭头变为 ▾，显示缩进的「分类」「标签」「归档」子项

- [ ] 下拉面板在深色模式下视觉一致
  - **Given** 站点处于深色模式，**When** 展开「文章」下拉，**Then** 下拉面板背景为深色、文字为浅色，图标颜色跟随文字，无突兀亮色块
